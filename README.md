Sammy International & Beauty Hub — Website Starter

A responsive static website built with HTML, CSS, and vanilla JavaScript for Sammy International & Beauty Hub.

Preview Locally

Open "index.html" in a web browser or use the preview feature in Spck Editor.

WhatsApp Enquiry Configuration

The WhatsApp enquiry functionality is configured in "script.js".

1. Open "script.js".
2. Locate "const BUSINESS_WHATSAPP_NUMBER = "2347065165710";".
3. Confirm that the number is correct and uses the international format with digits only.
4. Save the file and test the enquiry form to ensure it opens the correct WhatsApp conversation.

Before Publishing

Confirm the following:

- The business WhatsApp number and other contact information are accurate.
- The business location and service coverage area are correct.
- The countries and international number types available for enquiries are clearly established.
- All Facebook-related services comply with Meta's applicable terms and policies.
- Beauty service prices, operating hours, and home-service coverage are confirmed.
- Permission has been obtained to use business photographs and customer testimonials.

Files

- "index.html" — Main website structure, content, and sections.
- "style.css" — Website styling, layout, and responsive design.
- "script.js" — Mobile navigation and WhatsApp enquiry functionality.
- "favicon.png" — Website browser icon.

Hosting
